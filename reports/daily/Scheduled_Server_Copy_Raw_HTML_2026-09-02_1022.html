Executive Take

本測試只驗證一件事：排程執行環境產生的真實 UTF-8 HTML 檔案，是否可以透過 Google Drive import_document 並指定 keep_source_file_type，直接保留為 raw HTML。此測試不經 Google Doc staging、export、fetch、upload_file、Files/Library、sediment reference 或人工 URI。

Why It Matters

若成功，這會提供一個與既有 persistence graph 不同的 primitive：runtime file → import_document(keep_source_file_type) → raw Drive HTML。它可以繞過目前已觀察到的 Google Docs mutation safety gate，也繞過 export/fetch 產生的 connector reference 與 upload_file schema bridge。

若失敗，則可以確認目前 Scheduled execution context 對 file-consuming import action 也存在 policy 或 capability 限制。

Taiwan Transmission

此區塊用於 UTF-8 round-trip 驗證：台灣市場觀察 → connector transport → Google Drive raw file。內容沒有外部依賴，不需要 CSS、JS、圖片或字型下載。

Risk Light

Risk Light：Yellow。主要風險是 connector runtime 是否能把 top-level source_file 所指向的本地實體檔，自動轉換成 import_document 可接受的上傳物件，而不被 safety checks 阻擋。

Integrity Padding

A — The quick brown fox jumps over the lazy dog. 0123456789. 甲乙丙丁戊己庚辛壬癸。Connector rewrite test payload AAAAA BBBBB CCCCC DDDDD EEEEE FFFFF GGGGG HHHHH.

B — Preserve HTML semantics exactly enough for post-import verification. Symbols: → ← ↑ ↓ ✓ ✗ ★ ☆. Entities: &amp; &lt; &gt; &quot;.

C — This deterministic padding keeps the source in the intended 4–6 KB class and provides middle-of-file anchors for integrity checking. 台灣測試段落持續存在，避免只有開頭與結尾 marker。

D — No external rendering dependency. No script. No image. No network resource. No stylesheet link. Only inline CSS and semantic HTML.

Bottom Line

只有 Drive 中存在 exact filename 的非 Google-native、非空 raw HTML，且 required markers 與 closing </html> 經讀回驗證完整，才能判定 RAW_IMPORT_WORKS。
